# Unidad del sistema sin espacio

## Síntomas

- Windows informa poco espacio, una app no guarda archivos o una actualización pide más almacenamiento.

## Causas posibles

Archivos temporales, instaladores antiguos, aplicaciones grandes o archivos personales almacenados localmente.

## Solución paso a paso

1. Abre **Explorador de archivos → Este equipo** y anota el espacio libre de la unidad del sistema.
2. Abre **Configuración → Sistema → Almacenamiento → Recomendaciones de limpieza**. Revisa qué categorías ocupan más espacio.
3. Empieza por archivos temporales cuya eliminación esté autorizada. Revisa cada casilla. Conserva Descargas, Papelera y archivos de recuperación si el usuario aún necesita su contenido.
4. Si hace falta más espacio, revisa aplicaciones prescindibles con el usuario. Para archivos personales, usa una ubicación de respaldo aprobada y comprueba la copia antes de retirar el original.
5. Revisa el espacio libre de nuevo. Si la solicitud venía de Windows Update, usa el requisito que muestra Windows para ese paquete.

## Verificación

Compara el espacio libre antes y después. Repite la operación que fallaba, como guardar un archivo pequeño o descargar la actualización.

## Escalar si

El espacio vuelve a caer rápidamente, Windows muestra un error de disco o la limpieza necesaria afecta datos de trabajo o recuperación.
