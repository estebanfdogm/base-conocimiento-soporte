# AnyDesk no conecta o no permite controlar

## Síntomas

- La solicitud no llega, aparece un error de conexión o el técnico ve la pantalla sin poder usar teclado y ratón.

## Causas posibles

Equipo remoto desconectado, dirección equivocada, ventana cerrada bajo una configuración de acceso interactivo, permisos limitados o una red administrada que filtra la conexión.

## Solución paso a paso

1. Coordina la sesión por un canal acordado. Confirma que ambas personas saben quién solicita acceso y qué tarea se va a realizar.
2. Pide al usuario que compruebe su conexión y deje AnyDesk abierto. Confirma la dirección de sesión por el canal acordado y vuelve a intentar. Mantén ese identificador fuera de notas públicas.
3. Pide al usuario que verifique quién solicita la conexión en la ventana de aceptación. Para un diagnóstico visual basta el permiso de ver pantalla. Si hace falta controlar, acuerda y habilita teclado y ratón para esa sesión.
4. Si la solicitud no llega con AnyDesk abierto, revisa los ajustes de **Acceso interactivo** según la versión y copia el mensaje de error sin identificadores. Si la red está administrada, deriva el caso para que el responsable revise el filtrado.
5. Cierra la sesión al terminar y pide al usuario que verifique que el acceso remoto terminó.

## Verificación

Confirma que se vea la pantalla y, si se autorizó el control, prueba una acción inocua, como abrir Configuración.

## Escalar si

El error se repite en ambas direcciones, hay restricciones de red administrada o no se puede verificar quién solicita la conexión.
