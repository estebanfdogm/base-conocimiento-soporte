# PC lento en Windows 11

## Síntomas

- Windows tarda en iniciar, abrir programas o cambiar entre ventanas.
- La lentitud puede aparecer en todo el equipo o solo al usar una aplicación.

## Causas posibles

Procesos en segundo plano, demasiadas aplicaciones al inicio, memoria ocupada, poco espacio o una aplicación específica que consume recursos.

## Solución paso a paso

1. Pregunta cuándo empezó y si ocurre con una sola aplicación. Guarda el trabajo y reinicia si el equipo lleva mucho tiempo encendido.
2. Repite la acción lenta. Abre el **Administrador de tareas** con **Ctrl + Mayús + Esc**. En **Procesos**, revisa qué aplicación conocida usa CPU, memoria o disco de forma sostenida.
3. Cierra desde su propia ventana las aplicaciones que el usuario reconoce y puede dejar de usar. Espera si el consumo coincide con una actualización o sincronización esperada.
4. Si el problema se concentra al iniciar sesión, revisa **Aplicaciones de arranque**. Deshabilita solo aplicaciones conocidas y prescindibles, una por una. Conserva los agentes de seguridad y los componentes administrados.
5. Revisa **Configuración → Sistema → Almacenamiento**. Si la unidad está casi llena, aplica la [guía de espacio en disco](09-espacio-en-disco.md).

## Verificación

Repite la misma tarea y compara el tiempo aproximado y el uso de recursos antes y después. Para una falla de arranque, verifica después de un nuevo inicio.

## Escalar si

El equipo se congela aun con pocas aplicaciones, se apaga o aparecen errores del disco. Anota qué recurso se mantiene alto y qué proceso lo usa.
