# Dispositivo USB no reconocido

## Síntomas

- Windows muestra un aviso al conectar un periférico, o el dispositivo enciende pero no aparece donde se espera.

## Causas posibles

Puerto, cable o concentrador defectuoso, cable que solo carga, falta de alimentación o problema del controlador.

## Solución paso a paso

1. Si es una unidad que todavía aparece en Windows, detén cualquier copia y usa la expulsión segura antes de desconectarla.
2. Conecta el accesorio directamente al PC y prueba otro puerto. Si usa cable desmontable, prueba uno compatible con transferencia de datos.
3. Cambia un elemento a la vez. Prueba un periférico conocido en el mismo puerto y, si puedes, el periférico afectado en otro equipo autorizado.
4. Abre **Administrador de dispositivos**. Busca la categoría correspondiente o un dispositivo desconocido. En **Propiedades → General**, anota el código de **Estado del dispositivo**.
5. Si el fabricante requiere un controlador específico, identifica el modelo y sigue la guía oficial o el procedimiento de tu organización. Si una memoria con datos importantes pide formateo, deja de hacer cambios y escala el caso.

## Verificación

Verifica que Windows reconozca el periférico y que cumpla su función. Para una unidad, intenta abrir un archivo de prueba existente sin cambiar su contenido.

## Escalar si

El mismo dispositivo falla en varios equipos, el puerto tiene daño físico o los archivos son importantes y la unidad aparece ilegible.
